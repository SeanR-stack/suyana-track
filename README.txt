Suyana - Portfolio Climate Review (lender demo)
Built Nov 10, 2026. Data tested Nov 9, 2026.

OPEN IT (easiest)
  Double-click index.html. If it opens blank, open Safari first,
  then File > Open File and pick index.html.

RUN IT IN VS CODE (recommended)
  1. Unzip suyana-portfolio-demo.zip
  2. In VS Code: Terminal > New Terminal, then:
       cd ~/Downloads/suyana-portfolio-demo && python3 -m http.server 8080
  3. Open http://localhost:8080 in Safari
  (Stop with Ctrl+C when done.)

NEEDS INTERNET for the map tiles, fonts and the map library.
All farm data is embedded in the file itself.

WHAT IS REAL AND WHAT IS NOT
  - The 24 parcels are real OpenStreetMap farmland boundaries.
  - Weather and satellite numbers are real measurements from Nov 9, 2026.
  - Loan IDs and amounts are fictional. Flags say where to look first;
    they do not predict default.
